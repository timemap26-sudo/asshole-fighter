# 混蛋快打 Asshole Fighter

一個單方面挨打的格鬥遊戲。上傳某人的大頭照，對手就會變成那張臉。他**不會還手**，只會一直求饒；越打表情越慘，最後徹底崩潰。

純 HTML5 Canvas + JavaScript，不用安裝、不用伺服器，直接用瀏覽器打開 `index.html` 就能玩（手機也可以）。照片只在你的瀏覽器裡處理，不會上傳到任何地方。

## 玩法

1. 按「📷 上傳大頭照」選一張照片，拖曳／縮放／旋轉，把眼睛和嘴巴對準黃色虛線（頭頂留給頭髮）。
2. 輸入名字，按「開打！」。

方向鍵在右手、攻擊鍵在鍵盤左邊。

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 | `←` `→` | ◀ ▶ |
| 衝刺 | 連按兩下 `←` 或 `→` | 連點兩下 ◀ 或 ▶ |
| 跳（可以跳過對手、空中出招） | `↑` | ▲ |
| 蹲 | `↓` | ▼ |
| 賞巴掌 | `A`（或 `Z`） | 巴掌 |
| 拳頭揍 | `S`（或 `X`） | 拳頭 |
| 踢 | `D`（或 `C`） | 踢腿 |
| 過肩摔 | `F`（或 `V`） | 過肩摔 |
| 連環技 | `G` / 空白鍵 | 連環技 |

### 連環技指令
- `A A A` → **連環巴掌**
- `S S S` → **百裂拳**
- `A S D` → **沖天拳**（把人打上天，可以空中追打）
- `D D F` → **地獄摔**
- `G` / 空白鍵 → **連環技**；怒氣集滿時變成 **終極連環技**
- 空中只能用巴掌、拳頭、踢；摔技和連環技會在落地後自動施放

## 對手的崩潰過程
- 尊嚴值越低，精神狀態從「囂張 → 慌張 → 求饒 → 崩潰邊緣 → 瀕臨崩潰」一路往下掉
- 臉上會留下巴掌印、瘀青、黑眼圈、腫包，接著冒冷汗、皺眉、淚流滿面、流鼻血、嚎啕大哭、OK 繃、轉圈圈眼、臉部扭曲
- 血量低時會跪地磕頭求饒，邊打邊用語音求饒（可關閉）
- K.O. 時臉裂開、靈魂出竅 —— **崩潰！！**
